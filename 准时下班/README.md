## 运行

双击`index.html`即可离线玩，所有素材都在本目录。也可双击`启动游戏.command`启动本地5186服务；退出后在该终端按Ctrl+C关闭服务。

```bash
cd 准时下班
python3 -m http.server 5186 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:5186
```

纯HTML/CSS/JS单文件逻辑，无构建、无后端、无运行时远端素材。电脑与手机横屏更适合；手机竖屏也提供自适应菜单和触控按钮。原生Safari/iOS仍需实机验收。

## 新下班流程

小毛的专属工位位于中央四桌中的**左下桌**，有名牌、猫咪杯、小花瓶、深蓝桌垫、奶油色键盘与青绿色椅子。其余三桌坐着办公的NPC，正对显示器打字、读屏并回应技能。

1. 到自己的工位**发日报**。
2. 去右上打印区**取工牌**。
3. **最后回自己工位关机拿包**。没取卡不能提前拿包；不带包也要回工位关机。
4. 最后12秒到右下电梯按E进入候梯，**18:00自动发车**。一局真实150秒，17:57:30开始。

建议在拿包前探路或收集便签。大包拿起来后更显眼，不宜早早站在电梯口等老板经过。

## 选择包款与难度

| 包款 | 风格与难度 | 拿包后的负担 | 装忙准备 |
|---|---|---|---:|
| 空手 | 轻松，不带包 | 不减速，最不显眼；最后关机离席 | 0.6秒 |
| 小斜挎 | 轻装，奶油皮革链条包 | 基本不减速，低存在感 | 0.8秒 |
| 皮革托特 | 标准，中号通勤包 | 约慢7%，注意范围增加 | 1.15秒 |
| 大号双肩 | 挑战，大号海军蓝背包 | 约慢16%，更容易被注意 | 1.6秒 |

拿包前共同速度142px/s、掩护准备0.7秒；不同包的负担主要在拿包后体现。每种包款独立保存最高成绩与选项，旧版总纪录仍保留兼容。

## 操作与掩护

- **WASD / 方向键**：移动。点击地面自动绕桌椅走。
- **E**：操作身边任务与物品。取卡/喝咖啡不会被普通搭话反复清掉进度。
- **Q 闪身步**：朝行走/面向方向快速错身，冷却4秒；不可穿家具，不再复制人物残像。
- **X 狗熊哆嗦毛**：无遮挡范围内同事停顿2秒，老板0.8秒，冷却9秒；坐班同事也会停下，随后恢复办公。
- **空格 / 假装在忙**：在自己的工位、打印机或咖啡机旁停稳，等待掩护建立。打印区手持材料，咖啡角端杯看消息；移动解除，近距离仍会被识破。
- **咖啡机E互动**：两杯补给，每杯降低纠缠值28点。
- **Esc**：暂停/继续；切后台自动暂停，查看帮助不耗时。
- **M / 音符**：本地合成声音开关，默认静音。

桌椅与隔墙遮挡视线，角色按前后深度遮挡。纠缠值满会失败，拉开距离可恢复。场景有三张可选边界便签，收集可加分。临时巡查事件、坐班同事的抬头观察与拿包后的存在感会影响路线选择。仍使用单实体序列帧，每帧只画一个人物，防止重影。

## 修改指南

- `OWN_DESK`、`stations`设置专属工位与任务；`interact`限制最后收尾。
- `LOADOUTS`定义四档包具参数，`carrySpeed/exposure/coverDelay/coverStrength`决定实际负担；改名称和表现请同时检查菜单、侧栏与结算。
- `coverAt/updateCover/busy`负责三处装忙掩护；`updateSeated/drawSeated`负责坐班同事。
- `drawOwnDeskProps/drawCarriedBag/drawBusyProp`管理精细物品，禁止把袋子烘焙进背景再留下重复物品。
- `obstacles/chairs/findRoute/clearSight`共享碰撞与遮挡；移家具时同步场景、前景轮廓、任务点与巡逻路径。
- `bodyFrame/actorSprite`保持单帧实体，不要用人物叠化掩盖动作差异。
- `BEST_KEY`兼容旧总成绩，`BAG_BEST`分包款存成绩，`BAG_PREF`记选择，`PREF_KEY`记声音。没有局内计时存档。

游戏运行不需依赖；素材/测试工具使用当前已有sharp、Playwright与可选ffmpeg。生成原图、提示词和历史版本均保留。
