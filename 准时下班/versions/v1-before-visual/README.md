# 准时下班 · The 18:00 Escape Club

一个暖金日落色调的办公室潜行喜剧。主人公沿用《青铜之眼》的林悦人物参考，换上深蓝职业制服；躲开老板和同事的「聊两句」，在18:00准点撤离。

## 运行

双击本目录 `index.html` 即可离线游玩。也可双击 `启动游戏.command` 用本地服务打开。没有构建步骤、后端或远程运行资源。

```bash
cd 准时下班
python3 -m http.server 5186 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:5186
```

适合电脑和手机横屏。手机竖屏也有自适应界面与触控方向键；原生 Safari/iOS 仍需实机验收。

## 玩法

一局真实计时150秒，从17:57:30到18:00。完成三项收尾：左上工位发送日报、右上打印区取工牌、左下衣柜拿包。最后12秒，去右下角电梯按E进入候梯，18:00自动发车。提前到电梯可在门厅等待；忘记收尾、错过电梯或纠缠值满都会被留下加班。

- **WASD / 方向键**：移动；点击地面可自动绕桌寻路。
- **E**：与身边地点互动；任务需要短暂站定，行走或被搭话会打断。
- **Q 闪身步**：沿行走/面向方向快速错身，冷却4秒。短暂避开搭话，不可穿墙或穿桌。
- **X 狗熊哆嗦毛**：半径170内且无遮挡的同事愣住2秒，老板只愣0.8秒；冷却9秒。
- **空格 / 假装在忙**：工位附近停下装忙，降低被注意到的距离；移动解除。
- **咖啡机**：可用两杯，每杯降低纠缠值28点。
- **Esc**：暂停/继续。切到后台也自动暂停；查看手册不耗时。
- **M / 音符按钮**：声音开关。默认静音，开启后为本地Web Audio合成声。

老板和同事有独立巡查路线、视野、追随、搭话和停顿。桌子与隔墙遮挡视线；拉开距离会恢复纠缠值。17:58:35会发生12秒临时巡查加速事件。场景另有三张可选「边界感便签」，探索收集可提升评分；基础通关不强制收集。成功时计算下班评级，localStorage仅保存最高成绩和声音偏好，不保存局内计时。

## 修改指南

所有玩法都在 `index.html` 的脚本中。`fresh()` 设置150秒、角色和NPC出生点；`stations`设置收尾位置与交互耗时；`obstacles`是寻路、移动和闪身共用的碰撞几何。改变可走区域时同步检查`circleBlocked`和`findRoute`。

`desks`、`walls`与`drawRoom`控制办公场景；`drawNPC`和`paintHero`绘制角色。`clearSight`检查视野遮挡；`update`管理NPC巡查、纠缠、任务和倒计时。`dash`、`bear`、`busy`分别管理技能。星级/最高分在`finish`中；改存档格式时更新`BEST_KEY`，保留老版本文件。

人物与NPC表均保留原图；切帧脚本仅切分素材、不修改角色造型。素材处理工具`sharp`与Playwright来自当前已有本地环境，游戏运行无需这些依赖。测试可通过`BROWSER_PATH`覆盖浏览器路径。
