# V2 美术方向与接入约束

- 目标：参考《塞尔达：旷野之息》环境的柔和手绘质感、自然色彩与通透光影，构建原创古蜀遗迹；不用任天堂角色、标志、地图或游戏截图。
- 采用内置 image_gen 生成场景图，不调用需要 API Key 的外部付费 API。
- 三场景保持太阳、飞鸟、树枝三种叙事符号与既有互动逻辑；实际热点根据成图校准。
- 前厅：金色斜照、苔藓门拱、青铜门、残器、石碑、壁画。
- 祭坛：纵深洞窟天井、巨型青铜神树、发光树根、三座机关。
- 密室：圆形记忆祭坛、悬浮青铜面具、水面反光、幽蓝光。
- 行走区域：画面下方 76%–90% 的中间露台；前景植被只放角落。
- 旧版入口与完整运行资源保存在 versions/v1/，不覆盖其截图。
- 背景必须接入真实游戏后重新截图并走通三章，不能以生成图代替游戏运行截图。
