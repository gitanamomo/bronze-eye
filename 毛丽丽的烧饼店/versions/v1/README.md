# 毛丽丽的烧饼店

一款围绕手作烧饼、街坊人情与宠物陪伴的温暖经营游戏。V1 可玩原型，2026-11-13。

## 运行

直接用 Safari 或其他现代浏览器打开 `index.html`，无须安装依赖、构建或联网。推荐电脑横屏，支持手机竖屏。HTTP 运行：在本目录执行 `python3 -m http.server 5186 --bind 127.0.0.1`，打开 `http://127.0.0.1:5186`。部署 GitHub Pages 时，将本目录作为站点文件目录；当前尚未提交与发布。

## 玩法

- 每天营业约 4 分钟，开张前自行设定 60～600 元目标。
- 点击顾客订单自动选馅，依次揉面、包馅、入炉、出炉、交付。
- 火候表绿色区出炉额外获得 3 元小费；焦饼作废。数字 1/2/3 选馅，空格制作。
- 顾客耐心有限。狗狗「芝麻」会躺着晒太阳、偶尔散步；每 20 秒摸摸它可增加顾客 8 秒耐心。
- 达标奖励 25 元；可继续营业，或从暂停菜单提前收摊。未达标也可进入下一天。
- 180 元升级街角小铺，420 元升级麦香庭院（需先拥有小铺）；升级改变招牌与庭院装饰、增加顾客耐心。120 元升级恒温炭炉，使掌火速度降低 25%。
- 暂停、弹窗、离开页面时停止经营计时。每日结算与购买升级时保存至 localStorage。营业中刷新会丢失当天未结算进度。低资金会获得 20 元街坊援助。

## 文件结构

- `index.html`：全部界面、响应式 CSS、人物与狗狗动画、经济及订单逻辑。
- `assets/shop-scene.png`：本项目专属生成街景。
- `assets/0.webp`～`7.webp`：从原游戏复制保留的主角姿态；V1 使用 0、1 姿态。
- `assets/idle.webp`、`walk.webp`：原游戏狗狗精灵图，分别为 4 列 × 3 行。
- `artifacts/verify.cjs`：浏览器集成验证脚本（使用上级项目已有 Playwright）。
- `artifacts/verification.json`、截图：实际测试证据。

## 视觉素材

沿用原项目长卷发、白衬衫女性主角与黑色法斗，独立复制素材，不修改原游戏。人物以姿态切换、呼吸动画和情境对白表现。顾客暂为界面头像；本版并未实现逐帧揉面骨骼动画。扩建目前为招牌、装饰与经营参数变化，未制作三套独立建筑地图。

街景使用内置 imagegen 生成，提示词记录于 `artifacts/art-direction.md`。参赛前请根据具体赛事核对 AI 素材披露及授权要求。

## 修改指南

- 配方售价和成本：搜索 `recipes=`。
- 一日时长：搜索 `dayDuration=240`。
- 顾客与耐心：搜索 `people=`、`function addOrder`。
- 火候速度：搜索 `save.oven?9.3:7`；完美区为 48%～73%。
- 升级价格和效果：搜索 `function upgrades` 与 `save.level`。
- 存档键：`maolili-shaobing-v1`，与原游戏存档隔离。清空此键可重新开始。

## 验证与交付边界

以 `artifacts/verification.json` 为当前浏览器验证结果。测试包含实际按钮制作与售卖、暂停、宠物互动、余额不足、结算、扩建、重载存档与手机溢出。结算边界由测试脚本推进时间与收入模拟到达；不等同于长时间真人试玩。Safari/iPhone 真机体验及具体赛事适配仍待验收。
