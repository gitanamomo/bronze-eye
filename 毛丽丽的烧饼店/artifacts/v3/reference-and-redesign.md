## V2 的问题与 V3 的选择

| V2 问题 | V3 的具体改变 |
| --- | --- |
| 九步长流程锁住唯一一张饼，等待时没有别的事做 | 揉面、各炉位、泡茶拥有独立计时；制作和配餐交错进行 |
| 靠重复点击三次、四次延长操作 | 点击启动一次生产，过程中展示揉面擀皮动画；每个面皮和每张饼有各自实体 |
| 先做成完全定制成品，再碰运气等同要求客人 | 先烤通用酥饼底，以有限容量备餐架储存；出炉后按单开口夹已熟馅、加熟芝麻 |
| 唯一成品占住所有后续生产 | 2 个独立出餐盘，每盘最多 1 饼＋1 茶；第 3 个炉位可扩建获得 |
| 配单只有一项口味 | 饼＋定制辅料＋可选热茶，支持先送茶或先送饼；已送项标记，防重复收费 |
| 几乎没有备餐策略 | 有限面皮、熟饼、茶容量；熟饼留炉会焦；架满先腾盘，顾客耐心持续流逝 |
| 炉子升级仅降低火候游标速度 | 提高烤制速度、延长熟饼留炉容错；店铺扩建增加炉位、面皮/茶容量与耐心 |

这是基于参考资料做出的原创烧饼店设计，不是《飞机大厨》的完整复刻。保留毛丽丽、狗狗、老街、每日目标和长期扩建。没有照搬飞机客舱、原版素材、燃油付费系统或飞机托盘回收；街边外带使用纸袋，不增加不合理的回收流程。

## 明确的经营规则

- 生产：1.3 秒一张面皮（¥2），5 秒烤熟，熟后额外留炉 10 秒会焦；泡茶 3 秒（¥1）。开局 8 秒准备期。
- 容量：初始面皮 6、熟饼架 4、茶 3、炉位 2、出餐盘 2。升小铺后炉位 3，升架后熟饼位 6。
- 配餐：一张熟饼夹一种已熟馅；葱香、菜肉、豆沙成本分别 +¥1/+¥3/+¥2，售价 ¥12/¥18/¥15。茶售价 ¥5。
- 出餐：只送给所点击的顾客，辅料必须一致。饼/茶可分次送，逐项只收一次；完成整单后才加完成数和小费。错单原样留盘。
- 小费：完成整单时，剩余耐心 >60% 额外 ¥2；12 秒内连续完成 3 单开始获得连单小费。
- 收摊：3 分钟结束；库存不结转、材料成本不退，避免用退款抵消过度备餐。已送出单项的收入保留；未完成整单不计完成单数。
- 升级：营业前进行，防止在忙碌时升级重置设备或清除食物。
