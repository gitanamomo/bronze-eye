# 毛丽丽的烧饼店

温暖老街中的烧饼店经营游戏：毛丽丽逐张备面、并行烤饼，按街坊要求夹馅、配茶，完成每日营业目标，扩建店铺。狗狗「芝麻」在摊旁晒太阳，固定趴在摊边。

**当前版本：V6 · 2026-11-14。** 依据《飞机大厨》的官方介绍和玩法分析，将 V2 串行手作流程改为备餐、设备加工、配餐与出餐交错进行。参考与取舍见 [玩法研究记录](artifacts/v3/reference-and-redesign.md)。未启动原版 App，不声称完成原版试玩。

## 运行方式

直接在现代浏览器打开 `index.html`，不需要联网、安装依赖或构建工具。也可在本目录执行：

```bash
python3 -m http.server 5186 --bind 127.0.0.1
```

访问 `http://127.0.0.1:5186`。支持桌面、平板与手机触摸。源码目录：[GitHub · 毛丽丽的烧饼店](https://github.com/gitanamomo/bronze-eye/tree/main/毛丽丽的烧饼店)。可将本目录内容用于 GitHub Pages；此处不代表已完成线上部署验收。Safari/iPhone 真机尚未验收。

## 玩法：四个区域并行操作

1. **揉面擀饼**：点击启动，1.3 秒准备一张面皮，花费 ¥2；初始最多备 6 张。
2. **炭火烤炉**：点击空炉位消耗一张面皮。两个炉位各自烤制 5 秒；熟后点击取出，超过 10 秒未取会焦。烤制时继续备面、冲茶、配餐。
3. **出炉备餐**：初始可存 4 张熟饼。架满不能取炉里的饼，先把熟饼装盘腾位置。茶 3 秒泡一杯，成本 ¥1，最多备 3 杯。
4. **按单配餐**：先选 1/2 号盘，从架上拿饼，夹入一种已熟馅料，按订单设置葱、辣和熟芝麻，按需加入热茶。点击目标订单的「送出此盘」。

每张饼都是独立实体，盘中最多一张饼、一杯茶。两个盘可以为不同顾客同时配餐。可以先送茶再送饼；系统标记已送项目，防止重复收款。没有强制重复揉面点击，也没有全局锁死的九步流程。

| 成品 | 面皮＋熟馅成本 | 售价 |
| --- | --- | --- |
| 葱香酥饼 | ¥2＋¥1 | ¥12 |
| 梅菜肉夹饼 | ¥2＋¥3 | ¥18 |
| 红豆夹饼 | ¥2＋¥2 | ¥15 |
| 茉莉热茶 | ¥1 | ¥5 |

烤的是通用酥饼底，菜肉和豆沙为已熟馅料，出炉后开口夹入；芝麻也为熟芝麻，避免把生肉作为出炉后直接添加的馅料。辅料随夹馅附送。红豆只支持甜口和可选芝麻。

### 订单、收入与损耗

- 开局 8 秒供备餐；每场 3 分钟，自定目标 ¥60～¥300。
- 初始每 12 秒一位新顾客，最多等候 4 位，基础耐心 45 秒。
- 顾客要求具体口味、有无葱/辣/芝麻、是否配茶；交付只给所点击顾客，错误餐点留在盘中，不收款、不丢失。
- 单项交付即收到该项收入，完整订单才增加完成数并计算小费；已送项不能重复卖。
- 剩余耐心超过 60% 完成整单，获得 ¥2 小费；12 秒内连续完成三单起获得额外连单小费。
- 焦饼需要点炉位清理后再用；清空已夹馅饼损失成本。清空盘子时茶会放回茶位（需有空间）。
- 收摊时库存不结转、不退材料钱。已经送出的单项收入保留，未完成整单不计入完成单数。
- 达标奖励 ¥25。达标得一星；达标且流失 ≤1 再得一星；达标且无主动丢弃/清理焦饼记录再得一星。结算时的未售库存暂不计入浪费张数，但已花成本不退。

### 升级与宠物

设备与店铺升级在营业前进行，避免营业中升级清空炉位。

| 升级 | 费用 | 实际效果 |
| --- | --- | --- |
| 街角小铺 | ¥180 | 炉位 2→3，面皮 6→8、茶 3→4，顾客耐心 +5 秒 |
| 麦香庭院 | ¥420，需先有小铺 | 面皮 8→10、茶 4→5，顾客耐心再 +5 秒 |
| 稳火炭炉 | ¥120 | 烤制 5→3.5 秒，熟饼留炉容错 10→16 秒 |
| 加宽备餐架 | ¥90 | 熟饼架 4→6 张 |

小铺与庭院同时更换招牌，建筑背景目前共享一幅街景。摸摸芝麻每 20 秒可为所有等候顾客加 5 秒耐心。狗狗固定趴在摊边，不再行走。音效可手动开启。

切页、打开弹窗或主动暂停时，所有设备与顾客计时同时冻结。空格备面，T 泡茶，数字 1/2 选出餐盘。

## 存档

每日结算和购买升级时写入 localStorage。沿用 `maolili-shaobing-v1` 键，保留旧版日数、资金、口碑、扩建与日记。V1/V2 的炉子升级迁移为稳火炭炉效果。营业中刷新会丢失当日未保存进度，不支持跨浏览器同步。

开张时资金不足 ¥20 会获得街坊 ¥20 周转援助，营业中不无限补钱；需要控制备餐数量。清除此存档键可从头开始。旧版本快照共享存档键，比较快照时建议使用另一浏览器配置，避免相互覆盖。
